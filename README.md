# ReISO-NFR
An ISO/IEC 25010-Guided Retrieval–Reranking Approach for Fine-Grained Non-Functional Requirements Classification

Code, datasets, experimental results, and documentation for the ReISO-NFR study.

## Repository structure

- `notebooks/`: Google Colab experiment notebooks
- `data/`: processed dataset and fold assignments
- `results/`: evaluation results and predictions
- `figures/`: figures used in the paper
- `documentation/`: annotation guidelines and label cards
