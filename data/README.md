# Dataset

This folder contains the processed dataset, class mappings, and fixed five-fold cross-validation assignments.

dataset consists of 1793 samples and is labeled with 7 main quality characteristics (level1), which are:
L1 classes: 7 ['compatibility', 'maintainability', 'performance efficiency', 'portability', 'reliability', 'security', 'usability']
and it fine-grained classified under the sub-characteristics classes level2: 24
